## 收录范围

NAND、TLC/QLC、晶圆、裸片、SSD、eMMC/UFS；bit 量、产能、产出、稼动率、良率、ASP、供需比、TSV、堆叠等。

## 建议来源

原厂技术白皮书、产品手册；JEDEC、ONFI、NVMe 标准资料；研究数据库的定义与口径说明。

以上为附件中的来源建议或补充的取证原则，不表示已获取或验证具体资料。首次使用时请登记[来源记录](../../08-sources/README.md)。

## 条目应包含

术语中英文、定义、单位、计算方式、适用产品、统计周期、口径差异。

## 建议首批条目

术语词典；指标口径卡；标准与缩写索引。这些是待建设主题，尚未创建对应事实内容。
