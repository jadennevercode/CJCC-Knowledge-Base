# 业务材料③：典型事件规则审核表

[返回业务材料](../README.md) · P0（业务） · 状态：待业务填写/审核

围绕三类事件审核影响路径、触发条件、库存缓冲、替代条件和恢复逻辑，并补充容易误判的反例。AI 可依据历史资料形成初稿，由工艺、供应链、销售等相关业务人员集中审核。

| 事件类别 | 案例与反例收集重点 | 当前状态 |
| --- | --- | --- |
| 工厂停产 | 停产范围、持续时间、库存与转产条件；未造成明显损失的情形 | 待收集与审核 |
| 材料污染 | 涉及批次、工序、隔离与报废范围；及时拦截的情形 | 待收集与审核 |
| 重点客户需求或设计变更 | 需求变化、设计导入/退出、认证和采购节奏；替代需求或库存吸收的情形 | 待收集与审核 |

## 单条规则审核表

| 字段 | 待填写内容 |
| --- | --- |
| 规则编号 / 版本 / 类别 | 待分配 / 待填写 |
| 关联历史案例与来源 | 待填写；链接至事件条目并定位证据 |
| 适用主体、产品、地区与时间 | 待填写 |
| 触发条件及阈值依据 | 待填写；无依据不得编造数值 |
| 影响路径 | 待填写；逐段区分事实与推断 |
| 关键依赖及前提 | 待填写；链接关系记录 |
| 库存缓冲 | 待填写；库存层级、可用性与覆盖期间 |
| 替代条件及限制 | 待填写；工艺、认证、产能、交付时间 |
| 恢复条件与观察信号 | 待填写 |
| 反例 / 未触发条件 / 易误判点 | 待填写；无可用反例时标明待补充 |
| 与其他事件的共同瓶颈 | 待填写；注明重叠影响和计量方式 |
| 工艺 / 供应链 / 销售审核意见 | 待审核；仅由实际参与者填写 |
| 审核结论 | 待审核；通过 / 修改后复审 / 不适用 |
| 审核人 / 日期 / 下次复核触发条件 | 待填写 |

未具备实际审核记录时保持草稿或待审核状态。参考[事件模板](../../09-templates/event.md)与[事件案例模块](../../06-cross-chain/03-events-cases/README.md)。
