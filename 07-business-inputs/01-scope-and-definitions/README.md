# 业务材料①：建设范围与口径确认单

[返回业务材料](../README.md) · P0（业务） · 状态：待业务填写/确认

用于确认首期重点产品、应用、厂商，以及供给、需求、库存和供需比口径。AI 可整理候选清单，业务人员逐项勾选、修改或排除。

建议依据：客户已有产品目录、数据字典、模型说明及项目材料。
