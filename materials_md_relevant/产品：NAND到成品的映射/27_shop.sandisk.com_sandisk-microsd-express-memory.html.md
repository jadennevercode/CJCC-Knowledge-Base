# 闪迪 microSD Express 存储卡

闪迪™ microSD™ Express 技术可向下兼容 microSD™ UHS-I 设备，让作为下一代创造者和探索者的您做好准备，迎接未来更高速的设备。

兼容性

- 具备 microSD™ Express、microSD™ UHS-I 和 microSD™ UHS-II 插槽的设备。
- 在与 microSD™ UHS-I 和 microSD™ UHS-II 设备搭配使用时，可以 microSD™ UHS-I 的速度运行。
