# 来源材料归档（raw materials）

本目录旁的 `materials/` 为按台账「是否进模型」筛选后保留的原始材料快照；登记台账在本地维护，不随本仓库发布。

## 概览（裁剪日期 2026-11-11）

- 保留材料：**131 个文件**（PDF 64、HTML 66、HTM 1；一条材料可能同时含网页快照与多份 PDF）
- 入选口径：台账「是否进模型」为「是」，含「是，音频资料」「是，详细信息仍需要授权下载」「是，有几份白皮书需要进一步点击」「是，完整白皮书需要进一步点击」等带限定的变体
- 已移除：状态为重复、待进一步点击、需购买、报错、无信息及空值的材料，以及台账未登记的孤儿文件；未落盘的失败条目无对应文件

## 目录与命名

```text
materials/<业务环节>/<材料编号>_<域名>_<文件名主干>.<后缀>
```

- `业务环节`：多标签材料以主标签归入对应目录。
- 材料编号：`M###` 为新台账条目，`Sxxxxxxxxxxxx` 为旧副本条目。

## 许可与引用提示

本批文件为公开渠道抓取的快照，其中包含付费研究机构（Omdia、TrendForce、Yole、Gartner 等）与受限来源材料。是否可公开转载由库维护人确认；引用时以原始链接、发布机构和许可为准，不把抓取快照视为获得授权。受限条目的元数据（标题、链接、机构）亦请按敏感信息审慎处理。
