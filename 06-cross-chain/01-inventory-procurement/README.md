# 库存与采购概念

[返回总目录](../../README.md) · 优先级：P0 · 状态：目录已建立，知识条目待采集与审核。

## 收录范围

原料、在制品、原厂成品、渠道、OEM 库存；采购、消耗、备货、去库存。

## 建议来源

原厂、模组厂、终端厂商财报的存货附注与经营讨论；研究机构库存分析；客户库存管理制度及数据字典（受限材料仅记录授权引用）。

以上为附件中的来源建议或补充的取证原则，不表示已获取或验证具体资料。首次使用时请登记[来源记录](../../08-sources/README.md)。

## 条目应包含

库存层级、所有者、计量单位、时点/期间、库存天数算法、采购与消耗、财务/实物口径。

## 建议首批条目

库存概念卡；采购行为说明；库存指标口径。这些是待建设主题，尚未创建对应事实内容。
