# 条目模板

[返回总目录](../README.md)

复制模板至对应知识模块，填写后更新模块索引。模板本身不代表已有证据或结论。

| 模板 | 适用情况 |
| --- | --- |
| [知识条目](knowledge-entry.md) | 术语、材料、技术、产品、应用与政策说明 |
| [实体档案](entity.md) | 厂商、法人、品牌、合资公司与工厂基地 |
| [指标口径](metric.md) | 产能、产出、稼动率、bit 需求、库存、供需比及价格 |
| [历史事件](event.md) | 停产、污染、客户变更及多事件组合，包含反例 |
| [来源记录](source.md) | 文档、网页、论文、标准、数据库及可公开的业务证据 |

三份业务专用表单见[业务材料](../07-business-inputs/README.md)。
